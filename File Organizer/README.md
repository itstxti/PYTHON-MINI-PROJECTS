# File Organizer

A simple desktop file organizer built with **Python** and **Tkinter**.

## Features

* Select a folder to organize
* Preview files before organizing
* Organize files by type
* Search files by name or category
* View file size and modification date
* Find duplicate files
* Delete selected duplicate files
* Delete all duplicates while keeping one copy
* Undo the latest organization
* Customize file categories and extensions
* Switch between dark and light mode

## Tech Stack

* **Python 3**
* **Tkinter**

## Getting Started

### Requirements

* Python 3.x
* Tkinter

> [!NOTE]
>Tkinter is included with most standard Python installations

### Run

```bash
git clone https://github.com/itstxti/python-mini-projects.git
cd python-mini-projects/file organizer
python main.py
```

No external Python packages are required.
