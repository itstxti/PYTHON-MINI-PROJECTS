# LOVE

An animated heart built with **Python** and **Tkinter**.

## Tech Stack

* Python 3
* Tkinter

## Getting Started

### Requirements

* Python 3.x
* Tkinter

> [!NOTE]
> Tkinter is included with most standard Python installations

### Run

```bash
git clone https://github.com/itstxti/python-mini-projects.git
cd python-mini-projects/love
python love.py
```
