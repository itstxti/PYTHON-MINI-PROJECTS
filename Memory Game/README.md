# Memory Game

A desktop memory card game built with **Python** and **Tkinter**.

## Features

* Choose between Easy, Medium, and Hard difficulties
* Choose between Solo, Two Players, and Time Challenge modes
* Match pairs of cards to complete the board
* Play with different symbol categories
* Track attempts and completion time
* Play locally with two players on the same computer
* Take turns finding matching pairs
* Play against a time limit
* View Top 5 scores
* Enter your name for the leaderboard

## Difficulties

| Difficulty | Board | Time Challenge |
| ---------- | ----- | -------------: |
| Easy       | 4×4   |     60 seconds |
| Medium     | 4×6   |     90 seconds |
| Hard       | 6×6   |    120 seconds |

## Game Modes

### Solo

Play alone and try to complete the board using as few attempts as possible.

### Two Players

Play locally with another player on the same computer.

Players take turns selecting two cards. If the cards match, the same player continues their turn. If they do not match, the turn passes to the other player.

### Time Challenge

Complete the board before the time limit runs out.

## Tech Stack

* **Python 3**
* **Tkinter**

## Getting Started

### Requirements

* Python 3.x
* Tkinter

> [!NOTE]
>Tkinter is included with most standard Python installations

### Run

Clone the repository:

```bash
git clone https://github.com/itstxti/python-mini-projects.git
cd python-mini-projects/memory-game
python memory_game.py
```
