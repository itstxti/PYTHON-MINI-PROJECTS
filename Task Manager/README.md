# Task Manager

A desktop task management application built with **Python**, **Tkinter**, and **SQLite**.

## Features

* Add new tasks
* Edit existing tasks
* Delete tasks
* Mark tasks as completed
* Set task priority
* Set due dates using a calendar
* Search tasks by title or description
* Filter tasks by status
* Filter tasks by priority
* Sort tasks by due date, priority, title, or creation date
* Identify overdue tasks
* View task statistics
* Clear completed tasks

## Tech Stack

* **Python 3**
* **Tkinter**
* **SQLite**
* **tkcalendar**

## Getting Started

### Requirements

* Python 3.x
* Tkinter
* tkcalendar

> [!NOTE]
>Included with most standard Python installations

Install the required dependency:

```bash
pip install -r requirements.txt
```

### Run

Clone the repository:

```bash id="4q4qv7"
git clone https://github.com/itstxti/python-mini-projects.git
cd python-mini-projects/task-manager
python task_manager.py
```

A SQLite database will be created automatically when the application is first run.
