# Task Manager

A desktop task management application built with Python, Tkinter, and SQLite.

## Features

* Add new tasks
* Edit existing tasks
* Delete tasks
* Mark tasks as completed
* Set task priority
* Set due dates using a calendar
* Search tasks by title or description
* Filter tasks by status
* Filter tasks by priority
* Sort tasks by due date, priority, title, or creation date
* Identify overdue tasks
* View task statistics
* Clear completed tasks

## Tech Stack

Python

Tkinter

SQLite

tkcalendar

## Getting Started

### Requirements

Python 3.x

Tkinter

tkcalendar

Install tkcalendar:

pip install tkcalendar

### Run the application

Clone the repository:

git clone https://github.com/itstxti/python-mini-projects.git

Navigate to the project:

cd python-mini-projects/to-do-manager

Run the application:

python todo_manager.py

A SQLite database will be created automatically when the application is first run.
